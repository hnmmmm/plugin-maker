# 플러그인 메이커

블록을 쌓아서 **마인크래프트 서버 플러그인(.jar)** 을 만드는 프로그램입니다.
코딩을 몰라도 됩니다. 자바나 Maven 도 따로 설치하지 않아도 됩니다.

## 이런 걸 만들 수 있습니다

- `/spawn` `/home` `/warp` `/tpa` 같은 기본 명령어 (EssentialsX 스타일)
- 돈 · 점수 · 출석 보상 · 하루 한 번 킷 · 직업 보상
- **메뉴 디자이너**: 상자 화면을 눈으로 보며 꾸미고, 칸마다 "누르면"을 고릅니다. 메뉴 배경도 직접 그립니다 (1.19.3+)
- **커스텀 아이템 디자이너**: 그림·이름·설명·마법을 정하고 게임에서 보일 모양을 바로 봅니다
- **리소스팩 스튜디오**: 원래 아이템·블록·몹·화면(GUI) 그림을 직접 그려서 바꿉니다
- NPC 상인 · 상점
- 직접 그린 그림의 커스텀 아이템 + 리소스팩 자동 생성 · 나만의 제작법
- 나무 한 번에 베기 · 광물 한 번에 캐기 · 자동 제련 · 무덤 상자
- 채팅 꾸미기 · 점수판 · 탭 목록 · 보스바 · 서버 목록 설명(MOTD)
- 점검 모드 · 아이템 청소 · 잠수 감지 · 명령어 막기
- 더블 점프 · 점프대 · 앉기 · 떠 있는 글 · 표지판 명령어 · PvP 켜고 끄기

블록 312개(비슷한 건 ▾ 로 묶어서 팔레트에는 197개), 예제 65개가 들어 있습니다. 마크 **1.16.5 ~ 1.21.4** (Paper / Spigot) 를 지원합니다.

## 쓰는 법

1. 프로그램을 켜고 플러그인 이름과 마크 버전을 고릅니다.
2. 왼쪽 팔레트에서 **"~했을 때"** 블록을 끌어오고, 그 안에 하고 싶은 일을 쌓습니다.
   - 블록을 끌면 넣을 수 있는 자리가 **초록색**으로 보입니다. 못 넣는 곳에는 아예 안 붙고 이유를 알려줍니다.
   - 블록에 마우스를 올리면 설명과 "쓸 수 있는 곳"이 나옵니다.
   - 글자 칸을 누르면 **꾸민 글자 편집기**가 열립니다. 글자를 고르고 색·굵게를 누르면 블록 안에도 그 색으로 보입니다.
   - ▾ 가 있는 블록은 눌러서 종류를 바꿉니다. ＋ / − 로 칸 개수를 늘리고 줄입니다.
   - 아이템·몹처럼 긴 목록은 검색 창이 열립니다. 한글이나 영어로 찾습니다.
   - 고르기 창에는 **고른 마크 버전에 있는 아이템·블록·몹·효과·마법·소리가 전부** 아이콘과 함께 나옵니다
     (아이템은 인벤토리 모습, 몹은 얼굴, 효과는 효과 아이콘). 이름은 게임 공식 한국어 이름입니다.
     그림은 앱에 들어 있지 않고, 이 컴퓨터의 마인크래프트 파일을 읽거나 없으면 Mojang 공식 서버에서 그 버전 파일을 한 번 받습니다.
   - **마크 명령어** 블록으로 `/give` `/tp` `/summon` 같은 기본 명령어를 골라 실행합니다 (그 버전에 있는 것만 보입니다).
   - 왼쪽 위 **블록 검색** 칸에 "폭발", "돈" 처럼 쓰면 맞는 블록이 바로 나옵니다.
   - 막히면 위쪽 **"예제"** 에서 비슷한 걸 골라서 고쳐 씁니다.
3. **플러그인 만들기** 를 누르면 `.jar` 파일이 만들어집니다.
   - 처음 한 번만 자바(JDK)와 Maven 을 자동으로 받습니다. (약 200MB, 인터넷 필요)
   - **내 서버에 바로 넣기** 에 서버의 `plugins` 폴더를 골라두면 다 만든 jar 를 바로 복사합니다.
   - 그린 아이템이 있으면 `resourcepack.zip` 도 같이 만들어집니다.
4. 서버를 다시 켜면 플러그인이 동작합니다.

## 저장 위치

- 프로젝트: `문서\PluginMaker\projects` (저장할 때마다 바로 전 버전을 `.bak` 으로 남깁니다)
- 만든 플러그인: `문서\PluginMaker\exports\플러그인이름`
- 자동으로 받은 빌드 도구: `%APPDATA%\PluginMaker\tools`
- 버전별 목록 · 아이콘: `%APPDATA%\PluginMaker\mc-assets\<버전>` (지워도 다음에 다시 만듭니다)

## 개발자용

```bash
npm install
npm start          # 프로그램 실행
npm run dist       # Windows 설치 파일 만들기 → dist\PluginMaker-Setup-1.0.0.exe
```

| 파일 | 하는 일 |
|---|---|
| `defs.js` | 블록 정의 (블록 하나 = 한 줄, 블록 모양과 자바 코드를 둘 다 정합니다) |
| `gen.js` | 블록 → 자바 코드 |
| `workspace.js` | 블록 편집기 화면 (Blockly) |
| `templates.js` | 예제 |
| `pixel.js` · `pack.js` | 픽셀 그림판 · 리소스팩 |
| `tools.js` | 자바·Maven 자동 받기 (체크섬 확인) |
| `builder.js` · `main.js` | 프로젝트 파일 만들기 · 빌드 · 저장 |

예제는 유명한 플러그인들의 대표 기능을 블록으로 따라 만든 것이고, 그 플러그인들과는 관계가 없습니다.

## 받기

[Releases](../../releases) 에서 `PluginMaker-Setup-x.x.x.exe` 를 받아 실행합니다 (Windows 10/11 64비트).
